# P1–P10 V5：整体简化预算与局部几何保护

版本：`adaptive_p10_v5.0`。实现：`adaptive_p10_v5_policy.py`。

V5针对V4中P6吸收大量未知功能件和普通紧固件的问题设计。对象身份、拒识与局部装配功能仍使用既有融合结果；重新设计的是它们如何转化为整体简化预算，以及局部几何约束。功能未明确不是一个几何类别，曲面边多也不直接等于重要或难以简化。

## 十档完整定义

P按整体保护预算从低到高排序。一个形态可以跨档；表中的例子不是强制类别映射。局部截面、特征边、分量等约束独立生效，P低不意味着允许删除节点或破坏截面。

| 档位 | 整体预算意图 | 典型对象/证据 | 升档条件与边界 |
|---|---|---|---|
| P1 | 微小普通重复件 | 极小、重复的普通紧固/连接件 | 需要无冲突的普通紧固功能、有效几何、单一主体、同网格重复；未知功能件不得仅凭小尺寸进入P1 |
| P2 | 低贡献紧凑件 | 小型紧凑未知件、小型普通连接件 | 几何结构独立保留；局部显著、细长或复合结构可升档；不能据此断言不可见 |
| P3 | 简洁体块与普通连接 | 简单静态实体、简单支撑、一般标准连接 | 大尺寸可增加轮廓预算；不能将简单未知件直接命名为机架 |
| P4 | 一般表面与形状 | 板状外形、普通安装件、中等形态需求 | 板薄优先收紧截面约束；不因板薄统一升到P6 |
| P5 | 曲面与分布细节 | 中等尺度曲面体、混合细节、部分复合结构 | 曲面指标采用饱和贡献；几何无效或G关闭的未知功能件也可保守落在此档，但另标原因 |
| P6 | 显著路径与轮廓 | 对场景/局部装配有较大贡献的杆管路径、异形轮廓、高形态需求件 | 大小、形状及细节共同支持；曲面边超过阈值不再单独触发 |
| P7 | 耦合几何与功能接口 | 分散且复杂的复合几何、精密紧固、接口与检测安装 | 几何分量数量结合面积分布；语义接口与几何复合可以共享预算，保留各自来源 |
| P8 | 作业功能保护 | 执行器、检测控制件、工件候选 | 有融合功能依据；高网络置信度本身不构成升档条件 |
| P9 | 精密与工艺功能 | 导向、传动、工装、工具功能 | 功能先验保护；普通曲面复杂度不直接触发P10 |
| P10 | 关键功能与敏感几何联合保护 | 精密/工艺功能且截面敏感，或分散复杂细节共同成立 | 需要功能与几何联合证据；未知功能几何不能伪装成已识别的关键工艺件 |

P5还有明确的缺失证据回退用途，输出`budget_route`将其与曲面/细节驱动的P5分开。不会将这些原因混写成一个“未知件类别”。

## 功能未明确件：先形态分型，再分配预算

几何分型字段`geometry_budget_family`包含：

- `compact_simple`：紧凑、较简洁的实体。
- `compact_curved`：紧凑曲面实体。
- `compact_featured`：紧凑但锐边细节较多的实体。
- `plate`：板状表面。
- `rod`：杆/管状路径外形；不据此断定实心或空心。
- `elongated_sheet`：兼具细长与扁平的形态。
- `distributed_components`：具有较明显面积分散的多分量形态。

形态由OBB长、中、短轴比例识别：长/中≥4为细长形态，中/短≥8为板状形态，同时成立为细长扁平。多分量面积分散可覆盖上述分型，但原始形态仍单独保存。它们都是几何描述，不是语义识别真值。

同一形态继续根据以下独立量分配P2–P7：

1. **尺度贡献S**：全局相对尺寸在0.0025–0.16间进行对数归一化；H开启且存在至少3个成员的局部组时，局部尺寸最多补充剩余范围的15%。根设备标题不直接造成整组关键化。这里只是潜在视觉贡献，没有使用遮挡/可见性实测。
2. **形态需求D**：长/中从2–32形成杆状需求；中/短从4–64形成板状截面敏感度。整体需求取`max(杆状需求, 0.35×板状敏感度)`，避免大平板因厚度小而消耗过高的整体面数。
3. **细节C**：归一化锐边/曲面边长经`log1p`与上界饱和后加权，`C=0.55锐边+0.45曲面`。曲面细化程度影响这一代理指标，因此它只占有限预算贡献，不能充当真实简化误差。
4. **分量结构T**：`0.45×分量数量对数项 + 0.55×非最大分量面积占比项`。大量极小碎片与多个主要分量受到不同对待。分量来自位置焊接后的连接关系，不是准确的装配零件数。
5. **边界B**：开放边界长度的饱和代理项。它有较小贡献，不能单独证明边界是孔口或关键接口。

有效几何的预算分数为：

```text
q = 2 + 2S + 1.25D + 0.90C + 0.75T + 0.35B + 0.35×冲突指示
P_geometry = clamp(floor(q + 0.5), 2, 7)
```

每一项都输出到`geometry_budget_terms_json`，可以逐节点追溯。分数不是重要性概率。系数为显式工程先验，没有通过六模型P占比配额拟合；设计合理性仍需要误差、画质与资源测量验证。

未知功能件直接使用这一几何预算。语义已知件通常取功能保护先验与几何预算中更高者，避免关键功能因形状简单被忽略。

## 普通紧固件：三条独立路径

| 情况 | 处理 |
|---|---|
| 无冲突、全局尺寸<0.01、分量≤2且最大分量面积占比≥90% | 小型普通连接件相对几何预算降低一档，下限P2；螺纹曲面不会强制P6 |
| 上述条件成立，尺寸<0.0025、同网格重复≥4、长/中≤20 | 可进入P1；不剔除、不取消截面/边缘保护 |
| 尺寸较大、主体分散或证据冲突 | 不享受折扣，按几何预算分配；保留原类型假设与冲突记录，不擅自改名 |
| 融合功能是精密紧固/局部关键连接 | 走P7及以上功能保护先验，不能套用普通紧固件折扣 |

重复次数按同一场景的网格索引统计，是可验证的重复证据；导出为不同网格索引的相同零件不会被自动当作重复，可能少享受折扣。这是保守边界，不使用文件名猜测重复。

## 局部保护独立于整体档位

局部截面敏感度`R=max(杆状需求, 板状敏感度)`，不乘整体尺寸，不因语义置信度低而减弱：

```text
硬锁预算 = min(0.16, 档位基值 + 0.012R + 0.010锐边分数 + 0.012T)
误差上限 = 档位基值 / (1 + 0.7R + 0.4T + 0.15B)
若有冲突，再乘0.85
轴范围最大收缩 = 0.05 - 0.035R
特征软权重、特征权重、保护阈值也随R独立收紧
```

这组参数接入已有`schema=4`执行路径，保留有限QEM、局部特征分析、组范围与分量存在性检查。未知功能不会使几何保护失效。几何无效时禁止最高精度层预清理，并使用至少P5的保守预算；G被关闭的消融不偷读几何。

这些检查仍不能证明薄壁厚度、孔洞或全部拓扑不变。已有单网格探针也没有完整复现前端特征锁和递归cluster行为，不能用低P或一个成功探针替代画质验证。

## 构建模板与运行时

本轮复用V4十档近/中/远比例、屏幕误差基权重与基本误差模板，以隔离分配逻辑变化；局部约束独立计算。模板不是最终面数保留率。屏幕误差公式暂时沿用V4连续尺度/敏感度公式，因此P改变仍会改变运行时选择，不能继承V4的固定视角质量结论。

不复制旧的实测搜索结果、`quality_fallback`或实测质量声明到新策略。当前V5 CSV是可供后续构建核验的完整候选策略；旧部署与旧报告保留。尚未宣称V5能够降低多少显存、提高多少帧率。

## 一键复现与结果

```bat
run_p10_v5_design.bat
run_p10_v5_design.bat --models a
```

环境为`gpt-pointnext`。入口运行V5行为测试，然后验证固定输入的哈希，回放六组合×H0/H1，另加G对照与名称辅助，共每场景15个条件。六模型合计90组、165,000行策略；完整融合11,000节点。

输出：

- `lod_analysis_outputs/adaptive_p10_v5_20261021`：逐节点可执行策略CSV。
- `analysis_reports/adaptive_p10_v5_20261021/P1-P10_V5设计与六模型分配验证.md`：完整分配结果。
- `selected_node_changes.csv`：每个节点的旧/新P、形态、尺度、细节与局部约束。
- `previous_p6_cohorts.csv`：固定跟踪原P6未知功能件与普通紧固件的去向。
- `unresolved_geometry_families.csv`：全部未知功能件的几何分型与P1–P10占比。
- `all_profile_comparison.csv`：V4/V5同条件逐场景的P节点及实例三角形占比。
- `coefficient_sensitivity.csv`：尺寸、形态、细节、分量、边界系数分别上下扰动20%，以及同时扰动的档位敏感性；不是准确率证明。
- `provenance.json`：输入、代码和输出哈希；每个变体都核对对象身份/功能/拒识决定不变。

`--models a`等子集默认写入对应`subset_a`子目录，不覆盖已有六模型汇总。当前入口不替换V4部署；原`run_adaptive_p10_viewer.bat`仍读取V4。六模型属于开发场景。分配表检查完成后，仍需真实层次构建、多个视角的局部质量核验及GPU实测，才能评价整个成本—质量权衡。
