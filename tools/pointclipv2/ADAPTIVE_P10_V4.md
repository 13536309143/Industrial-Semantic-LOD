# 十档自适应几何保护策略

新版在v3融合身份与装配功能之上重新定义P1–P10。P表示保护配置，具体类型只是证据之一；同类对象可因局部作用、几何敏感性与尺度改变保护配置。不是分类网络升级，也不把CAD名称当作真实标注。

## 一键运行

```bat
run_adaptive_p10_comparison.bat
run_adaptive_p10_comparison.bat --no-export
run_adaptive_p10_runtime_validation.bat
run_adaptive_p10_viewer.bat "_downloaded_resources\a.glb"
run_adaptive_p10_viewer.bat "_downloaded_resources\a.glb" balanced
```

使用`gpt-pointnext`环境。要求已有配置好的CMake工程、六个GLB以及`lod_analysis_outputs/assembly_context_v3_20261020/scene_sources.json`中的完整推断。逐输入核验SHA256，代码与词库不相符时不能把旧神经输出冒充新推断。原来的`run_assembly_context_comparison.bat`现在转入新版；v3复现入口单独保存在`run_assembly_context_v3_legacy.bat`，重新运行旧导出会恢复旧策略。

第一个入口构建程序和探针、测试、生成完整策略、全量单网格几何核验，并备份导出。第二个入口另行完成真实cluster重建、串行GPU对比、固定视角截图和报告；不会把多个GPU测试同时运行。只测单个场景可传`--models a`。单场景报告不应冒充六场景报告。

查看入口默认使用已测试的严格画质设置（屏幕误差0.5）；第二参数`balanced`使用2。二者复用同一套几何缓存，画质与GPU时间的测量分开列出；不保证更严格画质同时提高帧率。入口开启文件映射、关闭未经证实有收益的压缩，缓存后缀独立于旧场景缓存。

## 十种策略

| P | 保护意图 | 常见适用证据 |
|---|---|---|
| P1 | 微小重复件 | 极小的普通标准件、同网格重复；未知或低置信度不能单独触发 |
| P2 | 普通重复标准件 | 普通紧固和标准连接，排除精密装配作用 |
| P3 | 简洁静态体块 | 形状简单的大体块、机架实体；先证实几何简单 |
| P4 | 普通表面与支撑 | 普通安装、支撑、外罩和简单表面 |
| P5 | 未决与均衡保护 | 身份未知、证据冲突、几何无效 |
| P6 | 细长薄壁与轮廓 | 管杆、薄板、敏感异形轮廓、多分离表面 |
| P7 | 功能接口与局部安装 | 流体接口、检测安装、精密紧固 |
| P8 | 驱动控制与作业对象 | 驱动、检测控制、工件候选 |
| P9 | 精密运动与工艺定位 | 导向、传动、夹具和工具功能 |
| P10 | 敏感关键工艺细节 | 工艺/精密功能与几何敏感性共同成立 |

等级可达并不要求每个场景都有十档。P1不自动剔除，所有配置禁止删除几何。小尺寸只能支持潜在屏幕贡献判断，不能证明被遮挡或不可见。M名称辅助与不使用名称的消融保持分开。

## 实际执行

`adaptive_p10_policy.py`定义意图、几何下限和连续调整；`run_adaptive_p10.py`执行全量回放与可行请求搜索。`schema=4`显式传递硬锁预算、软保护权重、增量QEM限制、包围范围收缩与连通分量保护。前端不再额外叠加旧档位硬锁，也不因语义置信度低而削弱几何约束。

`meshlod_simplify.h`在实际cluster构建中执行约束。失败的组回退到该组输入。硬约束不是用更高P标签代替；非流形点仍受保护，薄壁/孔洞特征仍由原有特征分析提出。连通分量存在性不是孔洞拓扑证明。

近/中/远比例是每次层次构建请求，并非最终几何保留率。`screen_error_weight`独立控制运行时细化；v4.3把几何敏感性与场景相对尺度耦合，避免微小复杂件一律提高显示精度。场景尺度只是潜在视觉贡献，不代表实际可见性。

对启用G且几何有效的节点，新增最高精度层预处理：请求比例`min(0.90, 0.45 + 0.045P)`，相对误差上限`0.0008/(1+0.18P)`。复用原有特征锁，检查分量存在性和0.5%的组包围范围收缩，失败回退。初始误差写入层次误差，不能把预处理后的几何假装成零误差原始数据。最高层清理与远层诊断不是同一测量。

旧六项文件名兼容，新第七项为NCGHM实测配置。UI编号从1开始，命令行枚举从0开始：**第七项对应`--semanticlodmode 6`**。重新打开场景并重建LOD使用新策略。CSV全行指纹参与缓存兼容，不复用其他策略的旧缓存。

## 验证与结果

报告目录：`analysis_reports/adaptive_p10_v4_20261020`。包括十档完整定义、六模型每P节点/三角形占比、原始输入远层单网格对照、包含最高层清理的真实缓存/进程内存/几何GPU字节/GPU时间，以及固定视角参考图。默认配置和严格画质配置分开报告；不把图像相似度换成语义识别准确率。

真实离屏测试显式等待加载与渲染就绪，固定1920×1080、supersample=1、关闭流式与阴影，顺序运行各进程。`GPU帧时间`不是桌面交互FPS，几何GPU字节不是整进程显存。文件映射会影响进程工作集。六模型均是开发诊断，不声称全局最优、完整拓扑证明或独立场景泛化。
