# 虚构模拟标注：不是人工真值或实验结果

本目录仅包含标注格式与软件流程演示数据。13个场景名称引用现有模型清单；全部520个示例零件、语义类别、功能角色和假设P档位均为虚构，每场景40条。

**这些记录不是对实际GLB节点的观察或人工判断，不能用来计算论文中的真实准确率，也不能作为算法有效性的证据。**

- 所有对象ID均以`SIM_ONLY_`开头，不对应真实节点。
- 每条记录明确包含`is_synthetic=true`、`is_human_annotated=false`。
- 实际节点与网格索引均为空。模拟类别与P档位只演示字段，不构成正式标注准则。
- 数据未使用融合预测来反推标签，也不包含算法准确率或各分支优劣结果。

主文件为`虚构模拟标注_非人工真值.jsonl`，一行一个JSON对象，可直接查看。`模拟数据说明.json`保存随机种子、规模与文件哈希。生成器仅使用Python标准库，可复现这份模拟样例。
