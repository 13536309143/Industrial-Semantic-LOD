# 十三模型：用户提供参考分布与融合消融结果的比较

**评价对象是P1–P10汇总分布的接近程度，不是逐零件准确率。**

参考数据为用户在本次消息中提供的13行百分比。用户将其描述为简单手动标记；尚无逐节点标注、实际标注数量、标注规则、盲标过程或独立复核记录。此前讨论中存在模拟数据需求，因此本报告将其保留为“用户提供、来源未核验的参考分布”，不认定为已核验人工真值，也不将本次距离排名作为方法有效性的独立证明。

用户称呼的HCG_H1在本报告按现有实验的NCG_H1理解：N=监督语义，C=开放视觉语义，G=显式几何；H1启用装配上下文，H0关闭该上下文。比较7种非空分支组合×H0/H1，共182个场景条件。

## 1. 比较方法与数据检查

使用总变差距离（TVD）：D=½Σ|预测占比−参考占比|，占比以百分数表示，因此D的单位是百分点、取值0至100，越小表示分布越接近。D=0只说明边际分布相同，不说明零件逐一判断正确。本报告不将100−D命名为准确率。

为消除两位小数的合计偏差，参考和算法分布均先归一化至100%。原报告的“<0.01%”按区间中点0.005%近似；非常接近的排名不宜过度解读。宏平均对13个场景等权，不按网格数量加权，因为参考实际标注样本数尚未提供。算法全量输出涵盖68,972个有效几何实例，M13的2个空网格除外；需要确认用户参考是否采用相同总体、是否只标记了子集。

## 7. 可支持的结论与不可支持的结论

就本次提供的参考占比而言，宏平均距离最小的配置是NCG_H1。NCG_H1的宏平均TVD为3.85个百分点，在10个场景中取得最小距离。完整融合加树相对不加树的平均距离改善为7.16个百分点。

删除监督N、开放C、几何G分支后，宏平均距离分别增加8.35、2.28、63.82个百分点。这些是当前完整系统及其固定回退规则下的条件消融差值，不能分解为各分支可相加的独立贡献。

开放分支的作用存在场景差异：NCG_H1在10个场景中较NG_H1更接近参考；M2、M7、M8则分别远离参考1.00、0.10、0.61个百分点。这提示可在后续独立验证集中研究开放分支的置信度、跨视图一致性与冲突门控，但不应依据当前参考表逐模型指定开关后，再将同一参考表作为最终测试结果。

几何分支的增益应结合规则实现理解：缺少几何分支时，未知功能实例大量进入P5回退；加入几何后可依据大小、形状和复杂度分配至其他档位。因此分布改善首先支持几何分支的策略细化作用，不等于证明监督或开放语义分类错误了相同比例的零件。

结构树与多源融合的作用可表述为“在所提供参考分布下，提高分配分布的一致性”。不能表述为“准确率超过90%”“统计显著优于”“结构保持更好”或“显存更低、帧率更高”。这些分别需要独立逐实例真值、适当统计设计、实际简化质量和运行时测量。

建议保留每个被标注实例的node_index、mesh_index、参考P档位或可接受范围、理由、标注人及是否查看算法输出。若表格是在查看NCG_H1后修订形成，必须披露其依赖性；若只标记子集，应在相同子集上比较各配置，不能把全量输出分布直接当作子集准确率。
