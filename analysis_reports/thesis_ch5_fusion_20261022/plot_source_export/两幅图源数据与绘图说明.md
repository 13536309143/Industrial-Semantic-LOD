# 两幅热力图的源数据与重绘说明

本数据包对应已有的`06_reference_signed_deviation_all_models.png`与`02_thirteen_scenes_fourteen_configurations_heatmap.png`。
Excel和CSV保存图中使用的数值，不从图片反向识别，不生成新的实验结果。Excel是便于导入的纯数值快照，不含依赖外部软件重算的公式。

## 二、图06：十三模型的参考中心偏差

### 1. 图中数值表示什么

对于模型m、配置v及策略k：

**有符号偏差Δ(m,v,k)＝算法占比p(m,v,k)－参考占比q(m,k)。**

单位为百分点。例如算法P3占比41.35%、参考为38.51%，偏差约为+2.84个百分点。文件保留的是归一化后实际用于图中的数值，故末位可能与直接减两位小数略有不同。

- 负数：算法在该P档分配的占比少于参考，对应蓝色。
- 正数：算法在该P档分配的占比多于参考，对应红色。
- 0：该P档占比与参考一致，对应白色附近。

符号描述的是某一档位占比偏多或偏少，不直接等同于具体零件欠保护或过度保护。

### 2. 在其他绘图程序中如何组织

1. 每个模型绘制一幅14×10矩阵热力图；行用配置，列用P1—P10。
2. 如果导入长表，先筛选`model_id`，将`configuration`作为行、`priority`作为列、`signed_diff_pp`作为色值。
3. 固定十三个模型的色标为**−85至+85百分点、中心0、线性刻度**。使用蓝—白—红配色，原图采用`RdBu_r`。
4. 模型排列顺序为M1至M13；每幅图均使用相同的配置和P档位顺序，不按软件默认字母排序。
5. 绿色边框标记该模型**总体TVD最小**的配置整行。可从`02_TVD_long_pp.csv`的`is_best_in_model=1`找到；不能按单个P档偏差分别找最低值来代替。

不对每个模型单独缩放色标，也不将偏差取绝对值后继续使用蓝—白—红含义；否则会改变图的解释。

## 三、图02：各模型的总体分布距离

### 1. 图中数值表示什么

**TVD(m,v)＝0.5×Σ[P1至P10] |算法占比－参考占比|。**

单位为百分点，取值范围理论上为0至100。原图根据本数据统一显示0至85，全部数据均在该范围内，没有截断。
数值越小，算法的P1—P10总体占比越接近参考。表中的`TVD_pp`即图中数值，图中文字显示两位小数，导出文件保留完整计算数值。

### 2. 重画设置

1. `02_TVD_matrix_pp.csv`第一列是配置标签，后13列依次为M1—M13；作为14×13矩阵导入，第一行与第一列作为类别标签，不纳入色值。
2. 横轴为模型M1—M13，纵轴为十四种配置。
3. 固定色标为**0至85百分点**，使用浅黄到深红色，原图采用`YlOrRd`。颜色越浅表示距离越低。
4. 同一模型中距离最小的配置加绿色边框；按列比较，不能按行比较。
5. 若需要散点、折线或分组柱状对照，可用182行的长表，`model_id`和`configuration`为类别，`TVD_pp`为数值。

当前NCG_H1在10个模型上距离最小；M2、M7、M8的最小距离配置为NG_H1。数据包保留这些例外，不将完整配置标成所有模型均最优。

## 四、重要的单位、顺序与精度

- 所有占比字段以**0—100的普通数字**存储：35.22表示35.22%，不是0.3522。导入时保持普通数值；直接套用Excel百分比格式会将其显示成3,522%。
- 偏差和TVD使用**百分点**，不需要除以100才能画原图。
- 原始参考占比保留用户提供的两位小数，部分行合计99.98%或100.01%；实际作图先将每行归一化至100%。
- 预测占比沿用此前报告的两位小数汇总；原报告的“<0.01%”在计算前使用中点0.005%，再逐行归一化。**不要换成原始计数占比后仍声称与这两张图完全相同**，因为少量末位数字可能变化。
- CSV保留完整计算精度，Excel默认显示6位小数；多出的位数是归一化与运算结果，不代表人工标记具有更多测量精度。
- 配置顺序固定为：N_H0、N_H1、C_H0、C_H1、G_H0、G_H1、NC_H0、NC_H1、NG_H0、NG_H1、CG_H0、CG_H1、NCG_H0、NCG_H1。
- N为监督语义，C为开放语义，G为显式几何。H0关闭装配上下文；H1包括局部拓扑、尺度及受范围限制的祖先名称。
- 参考分布由用户提供，独立人工标注过程尚未核验。两张图评价分布偏差，不给出逐零件准确率、几何质量或运行时性能。

## 五、字段说明

| 字段 | 含义与单位 |
|---|---|
| `model_id` | M1—M13；不能按字符串顺序自动排成M1、M10、M11等 |
| `configuration` | 十四种配置的类别标签 |
| `priority` | P1—P10；注意P10不可排在P2前 |
| `reference_pct` | 对应模型、对应P档位的归一化参考占比，0—100 |
| `prediction_pct` | 对应模型、配置及P档位的归一化算法占比，0—100 |
| `signed_diff_pp` | 算法占比减参考占比，百分点 |
| `absolute_diff_pp` | 上述偏差的绝对值，百分点 |
| `TVD_pp` | 当前模型及配置的总体分布距离；在长表十个P行中重复，汇总时不要重复计数 |
| `is_best_in_model` | 1表示该配置在当前模型中TVD最低，0表示不是 |
| `model_order`、`configuration_order`、`priority_order` | 用于维持原图顺序的整数排序键 |

标准色带的关键色阶在`csv/palette_color_stops.csv`中，提供标准化位置、对应百分点数值和十六进制颜色；其他软件可在这些色阶间插值，实际像素颜色也取决于软件的插值实现。详细设置及源文件SHA256见`plot_metadata.json`。
