# 公开材料约定

本仓库公开程序源码、通用配置、使用接口及有限的关键对比摘要。完整实验数据、论文材料、训练记录、权重、场景资产和可还原完整结果的图表保留在本地存储中，投稿前不纳入公共版本。

生成数据应写入被忽略的本地结果目录。通用程序配置可以使用JSON；包含测试指标、混淆矩阵、检查点来源或私人路径的模型记录不能作为通用配置提交。

提交前运行`python -s tools/maintenance/check_publication.py --staged`；推送前的钩子还会检查待推送历史，拦截实验目录及数据文件。检查用于防止常见误提交，文字中手工粘贴的结果仍需人工审阅。公开比较摘要只保留本页约定的少量汇总，增加结果需重新审查披露范围。

参与协作时使用清理后的仓库克隆，避免合并旧历史而重新带回实验材料。上游源码、许可证和公开文献内容保留原有归属。
